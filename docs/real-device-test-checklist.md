# Beeve 실기기 테스트 체크리스트

> 작성일: 2026-07-07  
> 대상 버전: App Store 재심사 제출 빌드  
> 심사 리젝 사유: Guideline 5.1.1(iv) 카메라 권한, Guideline 2.1(a) 회원탈퇴 버튼  
> Playwright 자동화로 검증 완료된 항목은 제외하고, 실기기에서만 확인 가능한 항목만 포함

## 테스트 환경 준비

| 항목 | 내용 |
|---|---|
| 우선 기기 | **iPad Air 11-inch (M3), iPadOS 26.6** (Apple 심사 기기와 동일) |
| 보조 기기 | iPhone (최신 iOS) |
| 빌드 형태 | **TestFlight 배포 빌드** (개발 빌드와 동작 차이 있을 수 있음) |

## 1. 카메라 권한 플로우 (Guideline 5.1.1(iv))

### 1-A. 최초 진입 플로우 (권한 이력 없는 클린 상태)

> 기기 설정 → Beeve 앱 삭제 후 재설치, 또는 설정 > 개인 정보 보호 > 카메라에서 Beeve 권한 초기화

- [ ] 카메라 기능 진입 시 커스텀 안내 모달이 먼저 표시되는지
- [ ] 커스텀 모달 버튼 텍스트가 **"계속하기"** (또는 중립 표현)인지 확인 — "허용", "허가" 단어 없어야 함
- [ ] "계속하기" 탭 → **iOS 시스템 권한 팝업이 연달아 뜨는지** 확인
- [ ] 시스템 팝업에서 "허용" 선택 → 카메라가 정상 작동하는지

### 1-B. 권한 거부 플로우

> 시스템 팝업에서 "허용 안 함" 선택 후 다시 카메라 기능 진입

- [ ] 시스템 팝업이 **다시 뜨지 않는지** (iOS 정책상 재요청 불가)
- [ ] 대신 커스텀 안내 화면에서 **"설정에서 허용하기"** 버튼이 표시되는지
- [ ] "설정에서 허용하기" 탭 → **Beeve 앱의 권한 설정 화면**으로 정확히 이동하는지
- [ ] 설정에서 카메라 권한 허용 후 앱으로 복귀 → 카메라가 정상 작동하는지

### 1-C. 기기별 확인

- [ ] **iPhone**에서 위 1-A, 1-B 플로우 동일 확인
- [ ] **iPad**에서 위 1-A, 1-B 플로우 동일 확인
- [ ] iPad 가로 모드에서 커스텀 모달 레이아웃 깨짐 없는지

## 2. 회원탈퇴 버튼 (Guideline 2.1(a))

### 2-A. 기본 동작 (iPad 우선)

> iPad Air 11-inch (M3), iPadOS 26.6

- [ ] 마이페이지 진입 → 화면 하단 **"회원탈퇴"** 버튼이 보이는지
- [ ] "회원탈퇴" 탭 → 확인 모달("탈퇴하면 모든 데이터가 삭제되며…")이 뜨는지
- [ ] 모달 **"취소"** 탭 → 모달 닫히고 마이페이지 유지되는지
- [ ] 모달 **"탈퇴하기"** 탭 → 탈퇴 처리 후 홈 화면으로 이동하는지

### 2-B. iPad 레이아웃 검증

- [ ] 세로 모드에서 버튼이 다른 요소에 **가려지거나 hit area가 어긋나지 않는지**
- [ ] 가로 모드(회전)에서도 버튼이 정상 위치·탭 가능한지
- [ ] Safe Area 밖으로 버튼이 밀려나 있지 않은지 (iPad 큰 화면)
- [ ] Split View / Slide Over 멀티태스킹 모드에서도 버튼이 탭 가능한지

### 2-C. 설치 경로별 확인

- [ ] **클린 설치** (기존 버전 삭제 후 새로 설치) → 회원탈퇴 버튼 정상 동작
- [ ] **업데이트 설치** (이전 버전 위에 업데이트 설치) → 회원탈퇴 버튼 정상 동작

### 2-D. 네트워크 환경별 확인

- [ ] Wi-Fi 정상 환경 → 탈퇴 정상 처리
- [ ] **느린 네트워크** (설정 > 개발자 > Network Link Conditioner: Very Bad Network) → 로딩 중 버튼 비활성화 유지, 완료 후 정상 처리
- [ ] **오프라인 → 온라인 전환** 시 탈퇴 버튼 동작 안정적인지 (오류 메시지 표시 또는 재시도 유도)

### 2-E. 엣지 케이스

- [ ] "탈퇴하기" 버튼 **연타** → 중복 API 호출 없이 안정적인지 ("처리 중…" 상태로 비활성화 확인)
- [ ] 탈퇴 API **실패** 시 모달이 닫히고 마이페이지 유지되는지 (무한 로딩 없는지)

## 3. 최종 제출 전 공통 체크

### 3-A. 빌드 검증

- [ ] TestFlight로 배포 빌드 설치 후 위 1, 2번 항목 **재확인** (개발 빌드와 배포 빌드 동작 차이 검증)
- [ ] Xcode Organizer에서 크래시 리포트 없는지 확인

### 3-B. Apple 심사 정보 준비

- [ ] App Review Information에 **테스트 계정** (이메일/비밀번호) 정확히 기재
- [ ] 심사 노트에 카메라 권한 수정 내용 및 회원탈퇴 버튼 수정 내용 명시
- [ ] 심사 노트 예시:
  ```
  [5.1.1(iv)] 카메라 커스텀 안내 모달의 버튼 텍스트를 중립 표현("계속하기")으로 변경하고,
  시스템 권한 팝업을 우회할 수 있는 "취소" 버튼을 제거했습니다.
  권한 거부 시 설정 앱 딥링크로 안내합니다.

  [2.1(a)] 회원탈퇴 버튼을 <div>에서 <button>으로 변경하고 최소 터치 영역(44pt)을 확보했습니다.
  탈퇴 확인 모달 및 DELETE /member API 연동을 완료했습니다.
  ```
